## 运行与重建

先阅读 `01_最终源码/00_使用说明.txt`。两套工程实际 PDS 入口为各自 `工程源码/work/run.tcl`，RTL 为 `work/rtl/design.v`；Multimodal 的 DDR vendor IP 与许可完整保留。ROM/RAM 初始化已嵌入冻结 RTL。

需要支持 PG2L200H 的 Pango Design Suite 及有效许可证；固件原构建使用 xPack riscv-none-elf-gcc 15.2.0。工具链安装包和商业许可证不包含在交付中。历史 Python 固件脚本依赖原 advanced 目录布局，迁移后需按 `source/firmware/build.json` 配置工具路径和源文件；不是开箱即用的一键固件重建。修改固件后还需将新映像嵌入实际综合 RTL。

CoreMark 实板记录：66 MHz、2000 次迭代、181.741831 CoreMark、约 2.753664 CoreMark/MHz；CRC 与 Correct operation validated 通过。保留既有验证证据，本次整理未重新综合或进行实板运行。
